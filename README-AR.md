# سكينة — هيكل مستعاد مبدئياً

هذه النسخة جُمعت من الملفات التي أمكن استرجاعها، وأُعيد إنشاء بعض ملفات التهيئة الأساسية. لم تُستعد نسخة المصدر الأصلية كاملة؛ لذلك اعتبرها نقطة انطلاق تحتاج مراجعة قبل النشر.

## المتطلبات

- Node.js 20 أو أحدث، وpnpm 10.
- قاعدة MySQL مع `DATABASE_URL` صحيح إذا أردت حفظ جلسات ومحاولات التلاوة.
- إعدادات Forge/OpenAI مطلوبة لميزات تحليل التلاوة والتخزين. استخدم `.env.example` كقائمة أسماء فقط.

## التشغيل المحلي

1. انسخ `.env.example` إلى `.env` وأدخل القيم محلياً. لا ترفع `.env` أو أي مفاتيح إلى GitHub.
2. ثبّت الحزم: `pnpm install`.
3. شغّل الخادم في الطرفية الأولى: `pnpm dev:server` (المنفذ الافتراضي 3000).
4. شغّل واجهة Vite في الطرفية الثانية: `pnpm dev:web` (المنفذ 5173، وطلبات `/api` تمر عبر proxy إلى الخادم).
5. افحص صحة الخادم من `/health`.

للبناء: `pnpm check` ثم `pnpm build`، ولتشغيل الإنتاج: `pnpm start`.

## حدود مهمة

- نقطة الدخول الجديدة تستخدم Express وtRPC؛ وتم التحقق من استجابة `/health` و`system.health` محلياً.
- لا يوجد في الملفات المستعادة مزود تسجيل دخول أو تحقق جلسة كامل. لهذا يظل كل طلب مجهولاً، والإجراءات المحمية مثل لوحة تقدم المستخدم ترفض الطلب حتى يُستكمل نظام المصادقة بأمان.
- `DATABASE_URL` لا يُنشئ قاعدة البيانات تلقائياً؛ يجب تجهيز MySQL وتشغيل migrations مناسبة بعد مراجعتها.
- ملفات الصور التي كانت مستضافة تحت `/manus-storage/` لم تُستعد كلها؛ قد تظهر أماكنها كصور مفقودة.
- لا تستخدم المشروع لمعالجة تسجيلات حقيقية أو تنشره للعامة قبل مراجعة الخصوصية، المصادقة، قاعدة البيانات، ومفاتيح التخزين وواجهات الذكاء الاصطناعي.
